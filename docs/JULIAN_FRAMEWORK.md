# Julian Project Framework

Dette prosjektet følger [Julian Project Framework](https://github.com/Border55-repo/Julian-Project-Framework).

- Prosjekt: **URKH-HOVED**
- Plattform: **Web / PWA / Android / iOS-kilde**
- Innføringsmodell: egen branch og pull request

## Regler

1. main skal være byggbar.
2. Endringer skal testes i pull request.
3. Versjoner følger SemVer.
4. Release-notater beskriver bare det som faktisk er levert.
5. Brukerdata og hemmeligheter skal ikke committes.
6. Lagring, gjenåpning og oppdatering testes når funksjonen håndterer varige data.
7. En release publiseres først når avtalte artefakter er kontrollert.

Se rammeverkets FRAMEWORK.md og docs/RELEASES.md for full standard.
