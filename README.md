# URKH

- [Åpne URKH](https://border55-repo.github.io/URKH-HOVED/)
- [Last ned nyeste Android-APK](https://github.com/Border55-repo/URKH-HOVED/releases/latest/download/URKH-Android.apk)
- **Installer på iPhone:** Åpne URKH-lenken i Safari, trykk Del og velg «Legg til på Hjem-skjermen».

URKH er et enkelt møteverktøy for Ullensaker Røde Kors Hjelpekorps, laget av **Julian Nordli**.

## Dette kan appen

- Lage møteinnkallinger med standardmal, kopiering og PDF-eksport.

- Lage lokalrådsreferat med eller uten møteopptak.
- Ta opp lokalrådsmøter med tydelig samtykkebekreftelse.
- Markere notater, vedtak og oppgaver under møtet.
- Stoppe opptaket og automatisk gjøre det om til tekst lokalt på enheten.
- Automatisk lage et redigerbart utkast i en fast referatmal.
- Kreve manuell kontroll før referatet kan eksporteres.
- Eksportere ferdig referat til PDF.
- Lagre og åpne møteprosjekter.
- Installeres på Android, Windows og Mac.
- Har et valgfritt Blålys-tema som huskes automatisk.

## Bruk

Åpne appen fra GitHub Pages. Trykk **Installer app** for å legge den på startskjermen eller datamaskinen. På Android kan APK-filen også lastes ned fra prosjektets Releases-side.

Første transkripsjon laster ned talemodellen. Dette kan ta litt tid. Opptaket og transkripsjonen behandles lokalt, men brukeren må alltid kontrollere navn, tall, vedtak og frister.

For PDF: fullfør kontrollpunktene, trykk **Eksporter til PDF**, og velg **Lagre som PDF** i utskriftsvinduet.

## Personvern

Informer alle deltakere før opptaket starter. Last ned opptaket separat dersom det skal bevares, og håndter opptak og referat etter organisasjonens rutiner.
