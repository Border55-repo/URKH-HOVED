# Sikkerhet

Ikke legg passord, nøkler, tokens, personopplysninger eller private brukerdata i GitHub.

- Bruk miljøvariabler eller GitHub Secrets for hemmeligheter.
- Logg ikke privat innhold.
- Bruk minst mulige tilganger.
- Dokumenter hva som lagres, hvor det lagres og hvordan det slettes.
- Roter straks en hemmelighet som ved et uhell blir eksponert.

Alvorlige sårbarheter skal meldes privat til prosjekteieren og ikke i et offentlig issue.
