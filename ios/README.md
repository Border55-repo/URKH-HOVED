# URKH for iPhone

Den raskeste installasjonen er nettappen: åpne URKH i Safari, trykk Del, velg «Legg til på Hjem-skjermen» og aktiver «Åpne som nettapp».

Denne mappen inneholder også kildekoden til den native iOS-innpakningen. Kjør `xcodegen generate` på en Mac, åpne `URKH.xcodeproj` i Xcode, velg Apple-team og bygg. Installasjon utenfor Safari krever Apples signering og en gyldig provisioning profile.
